KIT Navigation Map

📌 Overview

KIT Navigation Map is a full-stack web-based campus navigation system developed for Kolhapur Institute of Technology's College of Engineering. It enables users to locate departments, hostels, canteens, and other campus facilities using an interactive digital map.

The system integrates geospatial mapping with graph-based shortest path algorithms to provide accurate route guidance.

🚀 Features

1.Interactive campus map

2.18+ marked campus locations

3.Live user location tracking

4.Search functionality

5.Shortest path routing

6.Distance calculation in meters

7.Responsive UI

2️⃣ Create Virtual Environment
